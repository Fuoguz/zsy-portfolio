# 全站优化与发布记录

本轮发布于 2026-10-07 完成。用户已授权完成现有材料可支撑的优化并直接上线；真实项目补充材料延后。

## 完成范围

- 延续本轮前几次修复：首页身份与方向、单一项目集合及岗位排序、静态优先的 3D 工作室、业务结果分类、案例阅读结构、Globridge 沙盘接入决策、创意入口及已有广告脚本。
- 补齐导航当前位置、手机菜单 Escape / 焦点恢复 / 点击外部关闭、关闭状态 inert，以及跨页面加载完成后的锚点定位与焦点。
- 各公开页面统一阅读后的浏览 / 联系入口；加入中文加载失败与 404 恢复入口；畸形 URL 编码不再导致路由崩溃。
- 首页项目叙事采用简短标题与完整解释，统一中文页面标题、分享摘要及带结尾斜杠的 canonical。
- 图片查看器离开页面时清理滚动锁；录屏在页面隐藏时暂停；3D 关闭时释放模型、材质与纹理。
- 3D 场景及四张静态预览中的未核验数字改为 PLAN / ROLE / FLOW 等中性标签。导出和渲染使用内存副本，原始 Blend 未覆盖。
- 不新增个人经历、业务指标、功能实现范围或投放结果，不添加内容代写署名。真实素材缺口保留在 MISSING_INPUTS.md。
